# Modelos de site · Site Express

Vitrine pública dos modelos de site de uma página para pequenos negócios: barbearia, banho e tosa, confeitaria, clínica de estética, restaurante, oficina mecânica e estética automotiva. Todas as empresas são fictícias, criadas para demonstração; imagens e ilustrações são ilustrativas.

## Gerador de prévias

`gerador/` cria um site completo a partir de um arquivo JSON por cliente (prévia grátis, modelo do catálogo ou site final). Segmentos: clínica de estética, restaurante/lanchonete e oficina mecânica. Instruções em `gerador/LEIA-ME.md`.
