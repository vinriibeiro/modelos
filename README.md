# Modelos de site · Site Express

Vitrine pública dos modelos de site de uma página para pequenos negócios: barbearia, banho e tosa, confeitaria e estética automotiva. Todas as empresas são fictícias, criadas para demonstração; imagens e ilustrações são ilustrativas.

## Laboratório de soluções (`solucoes/`)

Galeria de demonstrações de automações para pequenos negócios, para testar pelo celular: OrçaCar (estética automotiva), Doce Fluxo (confeitaria), Ordem Express (assistência técnica) e Concilia Express (conciliação de vendas). HTML, CSS e JavaScript estáticos; estilos e utilitários compartilhados em `solucoes/assets/`. Dados fictícios, processados no navegador; nada é enviado. Cada demo tem um exemplo em um clique, validação, regra aplicada em linguagem simples, reinício e um botão comercial que leva ao WhatsApp.
